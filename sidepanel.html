🧮 Speed Calculator

With autocheck on, the calculator reads the speed at the action point and N frames later as soon as the clip has an action point, keeps rechecking while a slow clip is still loading, and then keeps End Speed, Speed Difference and the recommendation updating in realtime from the action point. While it is on, the Fetch buttons are hidden: pick the frames ahead in the calculator and the speeds are fetched automatically. It only runs while the calculator view is open.

On /review/ pages (and read-only clips) no speed is measured: the compliance check runs without the speed measurement, the autocheck stays idle, and the playhead is never moved. Saved automatically and shared with the options page.

"Fetch" seeks the clip automatically: start speed is read at the action point, end speed N frames later (set N with the buttons above). With both speeds filled, the recommendation picks from 6 options: Stop (end speed ≈ 0), Decelerate, Maintain speed, Accelerate, Remain stopped (stopped → stopped) and Resume motion (stopped → moving). "Apply to Page" opens the speed-change dropdown on the annotation page and picks the recommended option. You can tune the rules behind the recommendation (near-stop speed, maintain band…) in Settings (⚙ icon).
